## ✨ Overview

**Contact+** is a modern contact management application built around a Python-based contact book and transformed into a polished web experience.

The project started with the **Python contact-book logic and CRUD system**, which I designed and developed myself. I then used **Google AI Studio** to implement the web interface based on my own UI/UX concepts, designs, branding, and visual direction.

The result is a combination of **Python programming, web development, UI/UX design, branding, and AI-assisted development**.

---

## 🚀 Features

* 👤 **Add Contacts** — Create contacts with a name, phone number, email, and address.
* 🔎 **Search Contacts** — Quickly find contacts.
* 👁️ **View Contacts** — Access complete contact information.
* ✏️ **Edit Contacts** — Update existing information while keeping unchanged fields.
* 🗑️ **Delete Contacts** — Remove contacts with a confirmation step.
* 📋 **Contact Overview** — View and organize your saved contacts.
* 💾 **Persistent Data** — Contacts remain available after refreshing the application.
* 📱 **Responsive Design** — Designed to work across different screen sizes.
* ✨ **Modern Animations** — Smooth transitions and interactive UI elements.
* 🎨 **Custom Branding** — Original Contact+ identity and visual language.

## 🧠 Python Logic

The original contact management system was developed in Python using a dictionary-based data structure.

The core structure follows:

```python
contact_book = {
    "Name": {
        "phone": "Phone Number",
        "email": "Email Address",
        "address": "Address"
    }
}
```

The original Python system includes the main CRUD operations:

```text
Add Contact
View Contact
Edit Contact
Delete Contact
List All Contacts
```

This logic served as the functional foundation for the web version.
